# Revy Codex optimization kit

This kit contains the user's existing, unmodified ChatGPT Project files and `CODEX_TASK.md`, a complete instruction brief for Codex.

1. Unzip the kit into a local folder.
2. Open that folder in Codex (desktop app, CLI, or IDE).
3. Ask Codex: "Read CODEX_TASK.md and carry out the task completely using the two existing Revy Markdown files. Run real tests where available, and clearly mark any live-model tests that you cannot run."
4. Review output files and evaluation report before installing them in the ChatGPT Project.
5. Paste the revised `Revy_Project_Instructions_Optimized.md` into Project Settings -> Instructions; upload the master reference and keep continuity log up to date.

Codex may not have automatic access to the user's existing ChatGPT Project, and these local files will not sync there automatically.
